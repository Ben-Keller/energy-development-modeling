# Outputs

Generated artifacts are written here.

- `runs/`: one folder per run ID (`summary.json`, `results.csv`, integrated artifacts).
- Each run folder includes `exchange/` files for the MARIO runtime:
  `investment_shocks.csv`, `operating_shocks.csv`, `prices_and_taxes.csv`, `energy_service_balance.csv`.
- `figures/`: optional SVG charts from the backend utility script.
